# Forecasting System

This repository contains the codebase for a **forecasting system** designed to predict GitHub issue trends. The system leverages various machine learning and web technologies to enhance project efficiency and productivity by analyzing historical GitHub issues data. It was deployed on Google Cloud to enable **real-time predictions**, improving issue resolution speed and team productivity.

## Key Features
- **GitHub Issue Trend Forecasting**: The system predicts future trends in GitHub issues, helping teams prioritize critical issues.
- **Machine Learning Models**: Utilizes advanced models like LSTM (Long Short-Term Memory) for time-series forecasting to predict issue trends.
- **Real-Time Predictions**: Deployed on Google Cloud for real-time predictions, enabling faster decision-making.
- **Web Interface**: A user-friendly React-based front-end that displays the predicted trends and visualizes data in various chart formats.

## Project Structure

The project is divided into three main components:

- **Flask Backend** (`/src/Flask/`): Provides APIs for serving the forecasting model.
- **LSTM Forecasting Model** (`/src/LSTM-forecast/`): Implements the LSTM model for forecasting GitHub issue trends.
- **React Frontend** (`/src/React/`): The front-end interface that allows users to interact with the system, visualize data, and view predictions.


## Installation

### Prerequisites

Before setting up the project, ensure you have the following installed:
- Docker (for containerization)
- Python 3.x
- Node.js (for the React frontend)

### Backend Setup (Flask + LSTM Model)

1. **Navigate to the Flask backend directory**:
   ```bash
   cd src/Flask
   ```
   
   Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
    
  Run the Flask app:
    ```bash
     python app.py
     ```
    The Flask API should now be running at http://localhost:5000.
    
  To Dockerize: You can build and run the backend in a Docker container:
    ```bash
    docker build -t flask-backend .
    docker run -p 5000:5000 flask-backend
    ```

2. **Navigate to the LSTM forecasting directory**:
   ```bash
    cd src/LSTM-forecast
   ```
    Install dependencies:
   ```bash
    pip install -r requirements.txt
    ```
    Run the LSTM app:
   ```bash
    python app.py
    ```
    The LSTM model should now be ready to serve predictions at http://localhost:5001.
    
    To Dockerize: You can build and run the LSTM service in a Docker container:
    ```bash
    docker build -t lstm-forecast .
    docker run -p 5001:5001 lstm-forecast
    ```
    
3. **Navigate to the React frontend directory**:
    ```bash
    Copy
    cd src/React
    ```
    
    Install Node.js dependencies:
    ```bash
    npm install
    ```

    Run the React app:
    ```bash
    npm start
    ```
    The React app should now be running at http://localhost:3000.
    
    To Dockerize: You can build and run the React frontend in a Docker container:
    ```bash
    docker build -t react-frontend .
    docker run -p 3000:3000 react-frontend
    ```


## Deployment
This system has been deployed on Google Cloud for real-time predictions and can be accessed via the provided endpoints. You can use Google Cloud's App Engine or Google Kubernetes Engine (GKE) for scaling the backend and frontend services.

## Usage
Once the system is running, access the React frontend at http://localhost:3000 (or the deployed URL). Here, you can:
  1. View the predicted trends of GitHub issues.
  2. Interact with various types of data visualizations such as bar charts, line charts, and stack bars.
  3. Monitor real-time predictions generated by the Flask backend and the LSTM model.
